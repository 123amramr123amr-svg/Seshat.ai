# أسئلة برمجة بالعربي — س: صيغ السؤال مفصولة بـ |  ثم ج: الرد

س: الفرق بين = و == | ايه الفرق بين = و == | يعني ايه == | علامه == بتعمل ايه
ج: علامة = بتحط قيمة في متغير، زي x = 5. أما == فبتقارن بين قيمتين وبترجع True أو False.

س: يعني ايه return | return بتعمل ايه | فايده return | كلمه return
ج: كلمة return بتخلي الدالة ترجع قيمة للمكان اللي ناداها، وبتنهي تنفيذ الدالة عند السطر ده.

س: الفرق بين print و return | print ولا return
ج: print بتعرض القيمة على الشاشة بس، أما return بترجع القيمة عشان تستخدمها في باقي الكود.

س: ازاي اكتب كومنت في بايثون | الكومنت في بايثون | يعني ايه كومنت | يعني ايه comment
ج: الكومنت ملاحظة بتكتبها لنفسك والكمبيوتر بيتجاهلها. في بايثون بتبدأ بعلامة # وفي جافاسكريبت و C بتبدأ بـ //.

س: يعني ايه syntax error | طلعلي syntax error | خطا syntax | يعني ايه خطا في الصياغه
ج: الـ syntax error معناه إن الكود مكتوب بشكل غلط، زي قوس ناقص أو نقطتين منسية. راجع السطر اللي مكتوب في رسالة الخطأ.

س: يعني ايه index error | طلعلي index out of range | يعني ايه list index out of range | خطا index
ج: الخطأ ده معناه إنك بتطلب عنصر برقم مش موجود في الليست. افتكر إن العد بيبدأ من صفر، وآخر عنصر رقمه الطول ناقص واحد.

س: يعني ايه name error | طلعلي name is not defined | متغير مش متعرف
ج: الـ NameError معناه إنك استخدمت اسم متغير أو دالة قبل ما تعرفه، أو كتبت الاسم غلط.

س: يعني ايه type error | طلعلي type error | خطا في النوع
ج: الـ TypeError معناه إنك عملت عملية على نوع بيانات مينفعش معاها، زي جمع نص على رقم. حول النوع الأول بـ int أو str.

س: يعني ايه indentation error | طلعلي indentation error | خطا المسافات في بايثون | يعني ايه indentation
ج: بايثون بتعتمد على المسافات في أول السطر عشان تعرف الكود تبع أنهي بلوك. الخطأ ده معناه إن المسافات مش متساوية، خليها 4 مسافات لكل مستوى.

س: كودي فيه غلط | الكود مش شغال | ازاي اصلح الكود | عندي ايرور | ازاي الاقي الغلط في الكود
ج: اقرا رسالة الخطأ كويس وشوف رقم السطر، اطبع قيم المتغيرات بـ print عشان تعرف المشكلة فين، وجرب كل جزء لوحده.

س: يعني ايه نوع بيانات | انواع البيانات | انواع البيانات في بايثون | يعني ايه data type
ج: نوع البيانات بيحدد شكل القيمة. أشهر الأنواع في بايثون: int للأرقام الصحيحة، float للكسور، str للنصوص، bool لصح وغلط، و list للقوايم.

س: يعني ايه string | الاسترنج | يعني ايه نص في البرمجه
ج: الـ string هو نص، يعني مجموعة حروف بين علامتين تنصيص زي "hello".

س: يعني ايه integer | يعني ايه int | الفرق بين int و float | يعني ايه float
ج: الـ int رقم صحيح زي 5، والـ float رقم بكسر عشري زي 3.14.

س: يعني ايه boolean | يعني ايه bool | البوليان
ج: الـ boolean نوع بيانات ليه قيمتين بس: True أو False، وبنستخدمه في الشروط.

س: الفرق بين for و while | for ولا while | امتى استخدم while
ج: استخدم for لما تكون عارف عدد التكرارات أو بتلف على ليست، واستخدم while لما التكرار يعتمد على شرط ممكن يتغير.

س: يعني ايه import | import بتعمل ايه | يعني ايه مكتبه | يعني ايه مكتبه في البرمجه
ج: المكتبة كود جاهز كتبه حد تاني، و import بتخليك تستخدمه في برنامجك، زي import math.

س: يعني ايه pip | pip بتعمل ايه | ازاي انزل مكتبه في بايثون | ازاي اثبت مكتبه
ج: pip هو برنامج تثبيت مكتبات بايثون. اكتب في التيرمنال: pip install واسم المكتبة.

س: يعني ايه فريم ورك | يعني ايه framework | الفريم ورك
ج: الفريم ورك هيكل جاهز بتبني عليه برنامجك بدل ما تبدأ من الصفر، زي Flask و Django لمواقع بايثون.

س: يعني ايه json | ايه هو json | ملف json
ج: JSON صيغة نصية بسيطة لتخزين وتبادل البيانات على شكل مفتاح وقيمة، وبتستخدمها أغلب الـ APIs.

س: يعني ايه http | ايه هو http | بروتوكول http
ج: HTTP هو البروتوكول اللي المتصفح بيكلم بيه السيرفر. أشهر أنواع الطلبات GET لجلب بيانات و POST لإرسال بيانات.

س: يعني ايه سيرفر | السيرفر | يعني ايه server
ج: السيرفر كمبيوتر أو برنامج شغال طول الوقت، بيستقبل طلبات من الأجهزة التانية ويرد عليها.

س: يعني ايه ide | يعني ايه محرر اكواد | اكتب الكود فين | احسن برنامج اكتب عليه كود
ج: الـ IDE برنامج بتكتب فيه الكود وبيساعدك بالتلوين والإكمال التلقائي، زي VS Code و PyCharm.

س: يعني ايه تيرمنال | التيرمنال | يعني ايه terminal | يعني ايه command line
ج: التيرمنال شاشة بتكتب فيها أوامر نصية للكمبيوتر بدل ما تدوس على أيقونات، وبنشغل منها البرامج ونثبت المكتبات.

س: يعني ايه ستاك | يعني ايه stack | الستاك في البرمجه
ج: الستاك هيكل بيانات آخر عنصر يدخله هو أول عنصر يخرج منه، زي كومة أطباق.

س: يعني ايه كيو | يعني ايه queue | الطابور في البرمجه
ج: الكيو هيكل بيانات أول عنصر يدخله هو أول عنصر يخرج منه، زي الطابور قدام شباك التذاكر.

س: يعني ايه big o | يعني ايه تعقيد الخوارزميه | يعني ايه time complexity
ج: الـ Big O طريقة بنقيس بيها سرعة الخوارزمية لما حجم البيانات يكبر. مثلًا O(n) يعني الوقت بيزيد مع عدد العناصر.

س: يعني ايه هياكل بيانات | هياكل البيانات | يعني ايه data structures
ج: هياكل البيانات طرق لتنظيم البيانات في الذاكرة عشان نوصلها بسرعة، زي الليست والقاموس والستاك والشجرة.

س: يعني ايه برمجه كائنيه | يعني ايه oop | البرمجه الكائنيه
ج: البرمجة الكائنية OOP أسلوب بننظم فيه الكود في كلاسات وكائنات، كل كائن ليه بياناته ودواله.

س: يعني ايه وراثه في البرمجه | الوراثه | يعني ايه inheritance
ج: الوراثة إن كلاس ياخد خصائص ودوال كلاس تاني ويزود عليها، فمنكررش نفس الكود.

س: يعني ايه باراميتر | يعني ايه parameter | يعني ايه argument | مدخلات الداله
ج: الباراميتر هو المتغير اللي الدالة بتستقبله بين القوسين، والـ argument هو القيمة اللي بنبعتها لما ننادي الدالة.

س: يعني ايه اندكس | يعني ايه index | الاندكس في الليست
ج: الـ index هو رقم مكان العنصر في الليست، وبيبدأ من صفر. يعني أول عنصر رقمه 0.

س: ازاي ابقى مبرمج شاطر | ازاي اتحسن في البرمجه | نصايح للمبرمجين
ج: اكتب كود كل يوم، اعمل مشاريع صغيرة بنفسك، اقرا كود غيرك، ومتخافش من الأخطاء لأنها أحسن معلم.

س: اعمل مشروع ايه | افكار مشاريع برمجه | مشروع للمبتدئين
ج: جرب آلة حاسبة، لعبة تخمين رقم، قايمة مهام، أو موقع شخصي بسيط. ابدأ صغير وكبّر واحدة واحدة.

س: يعني ايه فلاسك | يعني ايه flask | ايه هو flask
ج: Flask فريم ورك خفيف بلغة بايثون لعمل مواقع و APIs، وأنا نفسي شغال عليه.

س: يعني ايه numpy | ايه هو numpy | مكتبه numpy
ج: NumPy مكتبة بايثون للحسابات على المصفوفات بسرعة، وهي اللي بشتغل بيها وأنا برد عليك.

س: يعني ايه pytorch | ايه هو pytorch | مكتبه pytorch
ج: PyTorch مكتبة بايثون لبناء وتدريب الشبكات العصبية، وأنا اتدربت بيها.
