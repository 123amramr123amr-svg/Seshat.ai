# خوفو (Khufu) — مولّد صور محلي

**خوفو** نموذج توليد صور مبني على DDPM (diffusion) يشتغل على CPU بس، من غير أي خدمة خارجية (مش pollinations.ai ولا أي API).

## المواصفات

- **النموذج:** UNet صغير (1.96 مليون بارامتر) مع class conditioning
- **التدريب:** Diffusion بـ 1000 خطوة، Sampling بـ DDIM (20/50/100 خطوة)
- **بيانات التدريب:** مشاهد مرسومة برمجيًا (19 فئة: شمس، قمر، نجمة، سحابة، طائر، شجرة، نخلة، بيت، عربية، قطة، كلب، حصان، جمل، هرم، جبل، بحر، مركب، سمكة، وردة)
- **الأبعاد المدعومة:** 32×32، 64×64، 96×96، 128×128 (المستخدم يختار)
- **اللغة:** عربي وإنجليزي (الكلمات المفتاحية)

## التشغيل

### التدريب
```bash
# تدريب من الصفر (حوالي 150 دقيقة أو 30,000 خطوة)
python3 train_khufu.py --steps 60000 --minutes 150 --batch 8

# استكمال التدريب
python3 train_khufu.py --resume --minutes 120
```

### التوليد من الكوماند لاين
```bash
# صورة قطة بأبعاد 64
python3 generate.py --subject cat --size 64 --steps 50 --out cat.png

# هرم بأبعاد 128 (عربي)
python3 generate.py --subject "ارسم هرم" --size 128 --steps 100 --seed 42 --out pyramid.png
```

### الويب أب
```bash
python3 app.py
# افتح http://localhost:5001
```

## الملفات

- `scenes.py` — رندر مشاهد التدريب (برمجيًا)
- `khufu_model.py` — نموذج UNet + DDPM/DDIM
- `train_khufu.py` — كود التدريب
- `generate.py` — توليد صور من الكوماند لاين
- `app.py` — Flask web app
- `templates/index.html` — واجهة الويب
- `data/khufu_latest.pt` — النموذج المدرّب (31 ميجا)
- `data/samples/` — عينات التدريب

## الحدود الواقعية

**اللي خوفو يقدر يعمله:**
- يولّد صور من نفسه (من غير إنترنت أو API)
- المستخدم يختار الأبعاد (32/64/96/128)
- يشتغل على CPU عادي (2 كور، 2 جيجا رام)
- يفهم عربي وإنجليزي

**اللي خوفو مش هيعمله:**
- مش صور واقعية (photorealistic) — دي مشاهد مبسطة بأشكال هندسية
- الجودة بتتحسن كل ما التدريب يطول (10,000+ خطوة عشان نتائج كويسة)
- التفاصيل محدودة بسبب صغر النموذج والبيانات
- أبطأ من نماذج GPU الكبيرة
